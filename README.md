# Bio Unit 1 Study App

Honors Biology - Chemistry of Life.

**Live: https://liz928.github.io/bio-flashcards/**

Two modes:
- **Flashcards** - 92 cards, tap to flip, swipe or arrow keys
- **Practice Test** - 50 questions matching the real test structure
  (3-4 per topic across 13 topics), instant feedback with explanations

Both filter by topic. Both track what you miss and let you review just those.
The test end screen breaks down misses BY TOPIC so you know what to restudy.
